# Fox Brain — دروازه مدل زبانی

فاز یک اتوماسیون Foxy1: دیباگ گفت‌وگومحور.

## معماری

```text
سرور ایران  →  Fox Brain روی Vercel  →  Groq / Gemini / OpenRouter / Cerebras
```

کلیدهای مدل روی Vercel می‌مانند، نه روی سرور ایران.

## چرا این معماری

سرور ایران به سرویس‌های مدل دسترسی ندارد ولی به vercel.app دارد.
همچنین اگر کلیدها روی سرور باشند، در صورت نفوذ همه‌شان لو می‌روند.

## متغیرهای لازم

اجباری:

```text
BRAIN_KEY
```

یک رشته تصادفی که خودت می‌سازی. بدون آن هر کسی می‌تواند سهمیه رایگانت را مصرف کند.

حداقل یکی از این‌ها لازم است:

```text
GROQ_API_KEY
GEMINI_API_KEY
OPENROUTER_API_KEY
CEREBRAS_API_KEY
```

هر چند تا که تنظیم کنی، به ترتیب امتحان می‌شوند. اگر یکی سهمیه‌اش تمام شود، خودکار به بعدی می‌رود.

## گرفتن کلید رایگان

```text
Groq       -> console.groq.com
Gemini     -> aistudio.google.com
OpenRouter -> openrouter.ai
Cerebras   -> cloud.cerebras.ai
```

هیچ‌کدام کارت اعتباری نمی‌خواهند.

## تست

```bash
curl -s https://NAME.vercel.app/health
```

خروجی درست:

```text
{"ok":true,"service":"fox-brain","providers_ready":["groq"],...}
```

## ابزار سمت سرور

فایل زیر روی سرور نصب می‌شود:

```text
foxy1-ask.py
```

استفاده:

```bash
python3 /opt/foxy1-monitor/foxy1-ask.py "چرا ربات کند شده؟"
```

گزینه‌ها:

```text
--context full   جمع‌آوری داده بیشتر
--dry            نمایش داده بدون ارسال به مدل
--health         بررسی سلامت دروازه
--prefer NAME    ترجیح یک ارائه‌دهنده خاص
```

## امنیت

- مقدارهای حساس قبل از ارسال به مدل پاک می‌شوند
- فهرست دستورهای تشخیصی در کد ثابت است، مدل نمی‌تواند تغییرش دهد
- این نسخه هیچ دستوری اجرا نمی‌کند، فقط تحلیل می‌کند
- سرویس‌های رایگان ممکن است داده را برای آموزش استفاده کنند، پس پاک‌سازی حیاتی است

## این نسخه چه نمی‌کند

- هیچ فایلی را تغییر نمی‌دهد
- هیچ سرویسی را ری‌استارت نمی‌کند
- هیچ دستوری اجرا نمی‌کند

اجرای دستور در فاز دو اضافه می‌شود، با تأیید دستی در تلگرام.
